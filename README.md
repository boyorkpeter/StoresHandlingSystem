# Stores Handling System

A desktop inventory management application built using JavaFX and JDBC.

## Features
- **Stock Management:** Record goods received (Stock In) and store issue vouchers (SIV).
- **Interactive UI:** Dynamic TableViews, side-sliding action panels, and low-stock highlighting.
- **Audit Logging:** Transaction history tracking with multi-axis filtering.
- **Reporting:** Export audit logs to Excel spreadsheets (`.xls`) and PDF vouchers.

## Tech Stack
- **Language:** Java
- **UI Framework:** JavaFX
- **Database:** MySQL / JDBC
- **Build Tool:** Maven
